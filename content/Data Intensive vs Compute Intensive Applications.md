## Introduction

### Data Intensive Application

An application is called *Data Intensive* if data is its primary challenge - the quantity of data, the complexity of data, or the speed at which it is changing.

Huge Quantity of data - petabytes, terabytes of data, so storing, moving and processing the data is the challenge.
Complexity of data - Highly connected data (social media graphs), unstructured data such as videos, images, logs etc.
Velocity of data - High speed streaming (Netflix, Twitch etc)

Here the bottleneck is data handling.

Ex: Google Search, Netflix Streaming, Social Media Feeds, Trading Systems etc.

### Compute Intensive Application

An application is called *Compute Intensive* where CPU cycles are the bottleneck.

A compute intensive application is one where raw CPU speed and efficiency determines how fast it can run. Speed of network, hard drive and other resources do not have any affect.

Ex: AI/ML model Training, Cryptography and hashing algorithm calculations, Video encoding/decoding, 3D rendering etc.
